# portfolio-demo

Bộ trang portfolio & landing demo (tĩnh, tự chứa 1 file mỗi trang).

## Nội dung

| File | Mô tả |
|------|-------|
| `index.html` | Trang tổng hợp link tới các portfolio |
| `ai-video-creator.html` | KHOI. — AI Video Creator (cinematic, dark) |
| `shortform-editor.html` | JADE — Short-form Video Editor (bold, trẻ trung) |
| `ai-social-designer.html` | MY BLOOM — AI Social Media Designer (sáng, pastel) |
| `landing-page-designer.html` | NAM° — Landing Page Designer (blueprint / technical) |
| `bolt-candles.html` | bolt — web bán nến thơm (có form đặt hàng) |

## Chạy thử

Mở trực tiếp file `.html` trong trình duyệt, hoặc chạy server tĩnh:

```bash
python3 -m http.server 8080
# rồi mở http://localhost:8080
```

> Trang mẫu demo. Ảnh minh hoạ lấy từ Unsplash (cần internet). Form đặt hàng không gửi dữ liệu đi đâu.
